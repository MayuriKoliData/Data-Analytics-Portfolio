📁 PROJECTS

1. SALES EXECUTIVE PERFORMANCE DASHBOARD – MICROSOFT EXCEL

Developed an interactive Excel dashboard to evaluate sales executive performance, monitor target achievement, compare total sales, and analyze sales performance across multiple cities.

Business Objective:
To understand how individual sales executives perform against their targets and identify performance differences across cities.

Key Features:
• Interactive city-wise filtering using slicers.
• Sales executive-wise total sales comparison.
• Target Hit Percentage analysis.
• Away From Target Percentage analysis.
• Performance comparison through interactive charts.
• PivotTables for dynamic sales performance reporting.

Tools & Technologies: Microsoft Excel, PivotTables, PivotCharts, Slicers, Data Analysis, KPI Reporting.

Project File: Sales Executive Performance Dashboard (.xlsm)
